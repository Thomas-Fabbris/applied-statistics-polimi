# Applied Statistics - PoliMi

A collection of Colab Notebooks used during the laboratory sessions of the course **Applied Statistics**, taught at **Politecnico di Milano** by:

- Prof. Michela Carlotta Massi
- Prof. Vittorio Torri

Academic Year: 2025/2026

## Repository Structure

```
applied-statistics-polimi/
└── Labs/
```

## Usage

The notebooks are designed to be opened in [Google Colab](https://colab.research.google.com/). You can open any notebook directly from GitHub by replacing `github.com` with `githubtocolab.com` in the URL, or by clicking the "Open in Colab" badge present in each notebook.
